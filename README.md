# Ezra Okari Portfolio

This repository contains the personal portfolio website for Ezra Okari.

## About
Ezra Okari is a Data Analyst, Full-Stack Developer, and Cybersecurity Practitioner based in Kenya. This portfolio presents his experience, projects, technical skills, and contact information.

## Main files
- `src/assets/data.min.js` — personal profile, contact details, project data, and portfolio content
- `src/index.html` — metadata and browser configuration
- `src/app/` — Angular app pages and components
- `src/assets/images/` — project and profile images

## Local development
```bash
npm install
ng serve
```

Then open:
```text
http://localhost:4200/
```

## Notes
This site is designed to be personalized by editing the data file in `src/assets/data.min.js`.
